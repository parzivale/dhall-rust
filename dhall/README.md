# `sessiond-dhall`

Implementation of the Dhall configuration language.

WARNING: This is an internal crate used for [`sessiond-serde-dhall`], you
probably want to use that instead.

WARNING: The API is very unstable and does not respect semver; use at your own risk. If you want to
use this crate directly anyways, have a look at [these tests].

[these tests]: https://github.com/parzivale/dhall-rust/blob/master/dhall/tests/misc.rs
[`sessiond-serde-dhall`]: https://docs.rs/sessiond-serde-dhall
